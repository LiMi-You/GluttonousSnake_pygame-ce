# [S1] 暂停菜单系统设计

## 概述

将现有的简单退出确认覆盖层（`QuitOverlay`）升级为完整的暂停菜单系统。菜单在游戏过程中按 ESC 弹出，提供继续游戏、设置、退出本局、退出游戏四个功能入口。

---

## [S2] 当前状态分析

### 现有实现

- `quit_overlay.py`：简单的"确定要退出游戏吗？"确认框
- 两个按钮：是（退出）/ 否（取消）
- 半透明黑色遮罩 + 居中确认框
- 支持键盘和鼠标操作

### 需要变更

- 从单一退出确认 → 多功能暂停菜单
- 按钮从 2 个扩展到 4 个
- 增加默认选中态、悬浮态的视觉区分
- 统一按钮颜色风格

---

## [S3] 功能需求

### 3.1 触发方式

| 触发条件 | 行为 |
|---------|------|
| 游戏中按 ESC | 弹出暂停菜单 |
| 菜单打开时按 ESC | 关闭菜单，返回游戏 |
| 菜单打开时按 CANCEL（手柄 B 键） | 关闭菜单，返回游戏 |

### 3.2 菜单按钮（从上到下竖排）

| 序号 | 按钮文字 | 动作 | 说明 |
|-----|---------|------|------|
| 1 | 继续游戏 | 关闭菜单 | 返回游戏，游戏恢复运行 |
| 2 | 游戏设置 | 占位 | 暂无子菜单，点击无效果或显示"敬请期待" |
| 3 | 退出本局 | 切换场景 | 返回大厅（LOBBY） |
| 4 | 退出游戏 | 退出程序 | 直接关闭窗口，无二次确认 |

### 3.3 暂停行为

- 菜单打开时，游戏逻辑**完全静止**
- `GameScreen.update()` 不被调用
- 蛇、NPC、道具、分数动画全部冻结
- 菜单关闭后，游戏从暂停点恢复

### 3.4 输入处理

**键盘：**
- `↑` / `W`：向上移动选中项
- `↓` / `S`：向下移动选中项
- `Enter` / `Space`：确认当前选中项
- `ESC`：关闭菜单（等同于"继续游戏"）

**鼠标：**
- 悬浮在按钮上 → 该按钮高亮
- 点击按钮 → 执行对应动作

**手柄（可选）：**
- `D-Pad ↑↓` 或 `Left Stick ↑↓`：移动选中项
- `A 键`：确认
- `B 键`：关闭菜单

## [S5] 数据结构设计

### 5.1 暂停菜单项定义

```python
# 暂停菜单按钮定义
PAUSE_MENU_ITEMS = [
```

|--------|-------|------|

| EXIT_LOBBY | `"LOBBY"` | 切换到大厅场景 |
| EXIT_GAME | 触发 `pygame.QUIT` | 退出程序 |

## [S7] 交互流程

### 7.1 打开菜单

```
玩家按 ESC
    ↓
SceneManager 检测到 GLOBAL_QUIT
    ↓
pause_menu.show()
    ↓
游戏 update() 被跳过（游戏静止）
    ↓
渲染：游戏画面 → 半透明遮罩 → 暂停菜单面板
```

### 7.2 选择"继续游戏"

```
玩家按 Enter 或点击"继续游戏"
    ↓
pause_menu 返回 "RESUME"
    ↓
pause_menu.hide()
    ↓
游戏 update() 恢复调用
    ↓
游戏从暂停点继续
```

### 7.3 选择"退出本局"

```
玩家按 Enter 或点击"退出本局"
    ↓
pause_menu 返回 "EXIT_LOBBY"
    ↓
SceneManager.switch("LOBBY")
    ↓
进入大厅场景
```

### 7.4 选择"退出游戏"

```
玩家按 Enter 或点击"退出游戏"
    ↓
pause_menu 返回 "EXIT_GAME"
    ↓
SceneManager 返回 False
    ↓
主循环退出，程序关闭
```

## [S8] 边界情况处理

| 情况 | 处理方式 |
|-----|---------|
| 游戏结束时按 ESC | 不弹出菜单（游戏已结束） |
| 开始界面按 ESC | 不弹出菜单（非游戏场景） |
| 手柄 B 键 | 关闭菜单（等同 ESC） |
| 快速连续按 ESC | 菜单toggle：开→关→开 |
| 鼠标移出窗口 | 菜单保持打开，无悬浮高亮 |

## [S9] 性能考虑

- 暂停菜单为纯 UI 绘制，无性能开销
- 游戏静止时不需要更新任何游戏逻辑
- 按钮文字可预渲染为 Surface 缓存（与现有实现一致）

## [S11] 验收标准

1. 游戏中按 ESC 弹出暂停菜单，游戏完全静止
2. 四个按钮竖排显示，统一青蓝色系
3. 默认选中"继续游戏"，悬浮/选中状态有亮度区分
4. 键盘 ↑↓ 选择，Enter 确认，ESC 关闭菜单
5. 鼠标悬浮高亮，点击执行对应动作
6. "继续游戏"关闭菜单，游戏恢复
7. "退出本局"返回大厅场景
8. "退出游戏"直接关闭程序
9. 游戏结束时不弹出菜单
10. 开始界面/大厅不弹出菜单
